# 路由表（10 种风格）

## 判断

| 信号 | 路由 |
| --- | --- |
| 只有主题 / 大纲 / 讲稿，要知识科普、动态图解、课件风，无真人出镜 | `explainer` |
| PPT / 课件转视频 | `explainer` |
| 表格 / 指标 / CSV → 数据动画 | `data-story` |
| 产品宣传片（有或将有真实截图） | `promo` |
| 文字快闪 / 金句卡 | `promo` |
| 动画短片 / MV 风（形状/文字节拍） | `animation` |
| 有真人口播或讲解录屏，AI/科技/工具类 | `talking-head` |
| 探店 / Vlog / 开箱 / 带货实拍 | `footage` |
| 长视频切片 / 高光短片 | `clip-long` |
| 软件教程录屏（主线录屏 + 步骤 overlays） | `screencast` |
| 生成数字人出镜 | **拒绝**（红线），不路由 |

## 追问上限

最多 3 问。信息已够就立刻路由，不要为问满 3 个而追问。

## 环境

路由确定后跑环境检查脚本（仓库：`../scripts/doctor.sh`；安装包：`./doctor.sh`）。**必须检查 ffmpeg 是否已装**（HyperFrames 本地渲染依赖）。

## 缺 skill 时

若目标 dist 包未安装：提示用户安装对应包（见仓库 README「安装（Mac）」），建议一次装齐。
