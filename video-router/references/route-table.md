# 路由表（本周最简）

## 判断

| 信号 | 路由 |
| --- | --- |
| 只有主题 / 大纲 / 讲稿，要知识科普、动态图解、课件风，无真人出镜 | `explainer` |
| 有真人口播或讲解录屏，要剪 AI/科技/工具类口播 | `talking-head` |
| 数据动画 | 暂不支持（预计 data-story） |
| 产品宣传片 / 文字快闪 | 暂不支持（promo，下周再定） |
| 探店 / Vlog / 带货实拍 | 暂不支持（footage） |
| 长视频切片 | 暂不支持（clip-long） |
| 动画短片 / MV | 暂不支持（animation） |
| 生成数字人出镜 | **拒绝**（红线），不路由 |

## 追问上限

最多 3 问。信息已够就立刻路由，不要为问满 3 个而追问。

## 环境

路由确定后跑环境检查脚本（仓库：`../scripts/doctor.sh`；安装包：`./doctor.sh`）。**必须检查 ffmpeg 是否已装**（HyperFrames 本地渲染依赖）。
