# B-roll 标记规则

对逐字稿扫描，遇到下列四类就标记一条 B-roll 建议：

| 类型 | 何时标 | 推荐 overlay |
| --- | --- | --- |
| 产品名 | 第一次说出具体产品/功能名 | `screenshot`（须用户真实截图） |
| 数字 | 百分比、金额、耗时、数量等关键数字 | `data` |
| 步骤 | 「第一步/然后/最后」等流程 | `steps` |
| 新概念 | 观众可能不懂的术语 | `concept` |

每条记录：`start`、`end`、`type`、`reason`、`overlay`、`asset`（截图路径或「待用户提供」）。

禁止：用代码画假产品界面；无截图时留白并提醒。
