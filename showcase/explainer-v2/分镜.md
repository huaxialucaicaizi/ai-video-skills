# 知识科普 v2 · 什么是 AI Agent（线稿手绘风）分镜表

- 规格：竖屏 1080×1920，30 fps，30.0 秒，无配音，屏幕文字讲完
- 结构：借 opus-video-prompts 第 07 号的讲解片结构（问题 → 是什么 → 怎么做 → 一个例子 → 收尾）
- 画风：线稿手绘，参考第 03 号「中华五千年」的思路（只学手法，不用其画面）
  - 米白纸面 `#F5F0E6` + 轻微纸纹；墨线 `#222`，线条一笔笔画出来；**唯一强调色：橘红 `#E8553D`**（标记笔、色块）
  - 线条「抖线」：SVG 扰动滤镜每 3 帧换一次种子（约 10 次/秒），像手绘动画；种子只由时间决定，逐帧确定
  - 主角：线稿小机器人「Agent」（方脑袋、天线、两只手），工具画成它拿起的物件（日历、放大镜、信封）
  - 字体：霞鹜文楷 LXGW WenKai（OFL，免费商用），只打包用到的字，随附 OFL
- 音乐：代码合成的无版权节拍，**120 BPM，1 小节 = 2 秒**；木琴感拨弦旋律 + 底鼓 + 拍手 + 沙锤，轻松俏皮；响度 -14 LUFS
  - 0–4 秒只有拨弦和沙锤（引子）；4 秒鼓进；22 秒短暂抽掉鼓（停顿感）；24 秒再进；30 秒落一个收尾音
- **所有切镜都落在小节线上**（偶数秒）；镜头内的元素出现落在拍点上（0.5 秒网格）
- 禁用：粒子爆炸、RGB 分离、镜头光晕、霓虹辉光、网格地面、闪烁背景、弹跳缓动、镜头抖动；屏幕文字不加句号
