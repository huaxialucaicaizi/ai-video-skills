# 像素风科普「什么是 AI Agent」· 测试提示词

> 这条样片不是由一句提示词生成的，而是按「分镜 → 关键帧 → 全片」三步、多轮对话做出来的。
> 下面把整个过程压缩成可以直接复制的提示词，供不同模型做对比测试。
> 建议两种都测：**A 一句话版**测模型自己的发挥，**B 导演版**测模型照规格执行的能力。

## A · 一句话版

```text
做一个 30 秒的竖屏像素风科普动画，讲「什么是 AI Agent」，用闯关游戏做比喻：Agent 是游戏主角，用户的一句话是任务，工具是它捡到的道具，办完就是通关。风格轻松有趣，配一段自己用代码合成的 8-bit 音乐，切镜卡在节拍上，渲染成 MP4。
```

---

## B · 导演版（和本仓库样片同规格）

```text
<goal>
做一条 30 秒竖屏（1080×1920，30fps）的像素风科普短片，主题「什么是 AI Agent」，输出 MP4。
比喻：一局闯关游戏 —— Agent 是游戏主角，你的一句话是任务，工具是它捡到的道具，办完就是通关。
</goal>

<direction>
- 真像素：所有画面先画在 180×320 的小画布上，再放大 6 倍（image-rendering: pixelated / 最近邻放大），硬边，不做平滑。
- 自定 16 色调色板：深夜蓝底、草绿、砖棕、暖黄、红、青、白、灰。不照搬任何游戏机或已有游戏的配色、角色、道具造型（不要问号方块、不要水管、不要「WORLD 1-1」这类标志性元素）。
- 主角：用字符矩阵手画的小机器人精灵（约 12×16 像素），有站立、跑步两帧、跳跃四种姿势。
- 中文必须清楚：使用免费商用的像素中文字体（如 Fusion Pixel 12px，OFL 协议），按 12px 原始尺寸绘制，阈值化去掉抗锯齿后再整数倍放大。屏幕文字不加句号。
- 禁用：粒子爆炸、RGB 分离、镜头光晕、霓虹辉光、闪烁背景、弹跳缓动、镜头抖动。
</direction>

<audio>
- 自己用代码合成，不用任何现成音乐或采样：方波旋律 + 低音 + 噪声鼓，C–Am–F–G 和弦循环，120 BPM（1 小节 = 2 秒）。
- 0–4 秒只有旋律引子；4 秒鼓进；22–24 秒鼓停一小节；最后一小节落一个收尾和弦。
- 4 种合成音效落在拍点上：顶方块「叮」（14/15/16 秒）、捡道具上行琶音（19/20/21 秒）、任务完成小号角（22.5 秒、26 秒）、计分「哔」（24/24.5/25 秒）。
- 响度统一到 -14 LUFS，真峰值不超过 -1 dBTP。渲染完再测一次响度（有的渲染器会把音量抬高）。
</audio>

<structure>
所有切镜落在小节线（偶数秒），镜头内的动作落在拍点（0.5 秒网格）。

1. 0–4s 游戏标题画面：夜空、星星（静止，不闪），标题「什么是 / AI Agent」从上方落下；2 秒弹出对话框，逐字打出「你说一句话 / 它把事办完」（「办完」黄色）；主角站在草地上，3 秒按拍跳一下。
   → 转场：10px 方块按对角线顺序盖满画面，再按同样顺序揭开（3.6–4.4s）。
2. 4–8s 左右对比：顶部「同样一句话」+ 任务框「帮我订周五的会议室」；左「聊天 AI」，NPC 头上的对话框打出「你可以先打开日历再看看谁有空…」，底部「只会告诉你」；6 秒右侧「AI Agent」主角开跑（地面滚动），手边带着日历，底部「会自己去做」，同时左半边变暗。
   → 转场：镜头推向主角，像素越放越大（7.6–8s）。
3. 8–12s 关卡标题卡：满屏红色，「第 1 关」，大字「AI Agent」落下；10 秒逐字打出「= 会自己动手的 AI」；主角按拍跳。
   → 转场：红色色块缩成一个方块，正好落在下一镜「想」方块的位置（11.6–12s）。
4. 12–18s 顶方块：标题「它怎么干活」；一排三个道具方块写着「想 / 做 / 看」；主角跑进来，在 14、15、16 秒各跳起来顶一个方块，方块弹出图标（灯泡 / 锤子 / 眼睛），上方列表依次出现「想一想 · 拆解目标」「动手做 · 调用工具」「看结果 · 检查对不对」；底部「想 → 做 → 看 循环到完成」；17 秒画出从第三块指回第一块的循环箭头。
   → 转场：横向卷轴，整屏左移进入下一段（17.6–18s）。
5. 18–24s 闯关捡道具：顶部任务栏「任务 / 订周五下午的会议室」，下方三格道具栏；主角从左往右跑，19/20/21 秒依次捡起日历、放大镜、信封，道具飞进道具栏，左侧列表出现「1 查日历 / 2 找空房 / 3 发邀请」；22 秒碰到终点旗、旗子升起；22.5 秒弹出「任务完成」。
   → 转场：4×4 有序抖动（Bayer）逐格变黑（23.6–24s）。
6. 24–26s 结算画面：黑底「结算」，三行在 24 / 24.5 / 25 秒依次跳出：「指令 1 句话」「步骤 3 步」「结果 办完」（办完黄色）。
   → 硬切。
7. 26–30s 通关：夜空，「通关」大字落下；主角放大到 3 倍居中，按拍举手；三个道具在身边上下浮动；28 秒弹出面板：「AI Agent」「目标 · 工具 · 检查」「给它目标 它自己找工具 / 做完再检查」。
</structure>

<build>
- 写成一个 HTML 页面：一个 draw(t) 函数，只根据时间 t 画出整帧（不依赖上一帧、不用随机数或 Date.now），这样任意一帧都能单独重现。
- 渲染：逐帧把 t 设为 n/30，截图后用 FFmpeg 合成 MP4 并混入音频（可用 Playwright/Puppeteer 截帧，或 HyperFrames、Remotion 等工具）。
- 字体、脚本都放在本地，渲染过程不依赖外网。
- 交付前从成片里均匀抽 20 帧以上拼成一张缩略图检查：文字有没有被遮挡或出界、转场是否完整、每镜内容是否齐全。
</build>

<start>
先给我一张 7 镜分镜表确认，再渲第 1 镜 3.5 秒、第 4 镜 16.5 秒、第 5 镜 23 秒三张关键帧让我看风格，我确认后再渲全片。
</start>
```

## 测试提示

- 网页版对话（Gemini、Claude.ai 等）一般不能直接渲染 MP4，只能给出 HTML。对比时，可以统一比较「能在浏览器里预览的 HTML」，或者把各家的 HTML 都用同一套渲染方式出片，这样比较才公平
- 要做一次性对比的话，B 版可以删掉 `<start>` 一段，让模型直接出全片
- 本仓库的成品代码在 `showcase/explainer-pixel/index.html`，音乐脚本在 `showcase/tools/beat.py`，可以作为参照答案
